
#  Clínica Vida+ | Sistema de Cadastro de Pacientes

## 📌 Sobre o projeto

O **Clínica Vida+** é um sistema desenvolvido em Python como parte do Projeto Integrado do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é simular um sistema simples de gerenciamento de pacientes de uma clínica médica, permitindo cadastrar, consultar e organizar informações por meio de um menu interativo no terminal.

O projeto foi desenvolvido para colocar em prática conceitos fundamentais de lógica de programação e manipulação de dados utilizando Python.

##  Funcionalidades
- **Cadastro de pacientes:** permite registrar nome, idade e telefone.
- **Estatísticas:** apresenta o total de pacientes, a média de idade e identifica o paciente mais novo e o mais velho.
- **Busca de pacientes:** permite localizar registros pelo nome.
- **Listagem de pacientes:** exibe todos os registros cadastrados.
- **Tratamento de erros:** identifica entradas não numéricas na idade.
- **Menu interativo:** permite navegar pelas funcionalidades.

##  Tecnologias utilizadas
- Python 3
- Listas e dicionários
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`, `for`)
- Tratamento de exceções (`try/except`)
- Funções nativas (`len`, `sum`, `min`, `max`, `enumerate`)

##  Exemplo de funcionamento
```text
=== SISTEMA CLÍNICA VIDA+ ===

1. Cadastrar paciente
2. Ver estatísticas
3. Buscar paciente
4. Listar todos os pacientes
5. Sair
```
